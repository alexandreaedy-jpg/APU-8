# APU-8 Light Feature Matrix

## Core Marketing Rule

The **Light** must never be framed as:

- a crippled version
- a reduced sound engine
- a frustrating compromise

The **Deluxe** must never be framed as:

- "the one that actually does everything"

The smart product promise is:

- **Light = same sound engine, compact access**
- **Deluxe = same sound engine, full hands-on access**

In other words:

- **Light is a complete module**
- **Deluxe is a complete instrument**

That distinction is extremely important.

## Marketing Positioning

### Light promise

"A compact NES sound module with the essential controls on the surface and full depth available over MIDI CC."

### Deluxe promise

"A premium dedicated NES instrument with immediate front-panel control over the full sound engine."

## What Must Stay Shared

To keep the product line honest and attractive, both versions should share as much as possible of the real sonic promise:

- same core audio engine
- same voice architecture
- same basic patch compatibility
- same MIDI CC depth
- same core musical potential

This means the Deluxe should **not** be sold as:

- more voices
- a better synthesis engine
- the "real" sound version

Instead, Deluxe should be sold as:

- faster access
- deeper immediacy
- stronger live workflow
- more autonomy from DAW / MIDI mapping

## APU-8 Light - Feature Table

| Area | Light feature | Why it belongs on Light |
|---|---|---|
| Core identity | Compact expansion module | Keeps the product approachable and affordable |
| Sound engine | Full shared engine | Prevents Light from feeling artificially limited |
| Voice access | Voice selector in front panel | Essential direct interaction |
| Preset / mode access | A few dedicated buttons | Gives immediate access without clutter |
| MIDI control | Full MIDI CC support | Makes Light deep despite minimal hardware |
| MIDI input | Yes | Mandatory for the concept |
| Basic live interaction | Essential performance buttons only | Enough for identity, not enough to complicate the box |
| Visual feedback | Simple LEDs / status indicators | Cheap, readable, enough for a compact module |
| Portability | Small controller-like body | Strong emotional and aesthetic value |
| Price goal | Below `250 €` | Critical to widen the buyer funnel |

## Suggested Front-Panel Features For Light

### Must-have

- voice selector
- a few core mode buttons
- one or two utility buttons for navigation or state changes
- MIDI activity / status LEDs
- maybe one compact selector if it simplifies use a lot

### Very plausible

- preset up/down
- macro button(s)
- performance mode toggle
- arp on/off or modulation mode toggle if genuinely useful

### Optional but risky

- one single encoder
- one single multifunction knob

These can help, but only if they do not make the product feel confusing or "mini workstation-like".

## What Light Should Deliberately Avoid

These are the things that make Light drift away from its purpose:

- sliders
- full ADSR panel
- per-function modulation knobs
- crowded switch arrays
- large screen
- menu-heavy interaction
- "tiny Deluxe" syndrome

If Light tries to imitate the Deluxe in miniature, it loses its clarity.

## What Light Must Still Be Able To Do

Even with a minimal front panel, the Light should still feel complete because:

- every important synth function exists in the engine
- deeper editing remains reachable over MIDI CC
- it can still be serious in studio use
- it can still be musically expressive

The user must feel:

"I bought the compact version, not the incomplete version."

## Deluxe Promise Relative To Light

The smartest Deluxe promise is not:

- "more sound"

It is:

- "more immediacy"
- "more control on the panel"
- "less dependency on external mapping"
- "more performance confidence"

## Deluxe Value Messages That Work

### Good messages

- "Everything important is right under your fingers."
- "Built for players who want direct control."
- "The flagship performance version."
- "The same sound engine, with the full tactile experience."

### Bad messages

- "Unlocks the full synth."
- "The complete version."
- "The pro version of the real engine."

Those would damage the Light instantly.

## Best Positioning Pair

### Light

- compact
- immediate
- affordable
- clever
- studio-friendly
- controller-like

### Deluxe

- expressive
- premium
- instrument-like
- live-friendly
- autonomous
- flagship

## Practical Feature Hierarchy

### Light = direct essentials

- voice choice
- a few mode actions
- compact status feedback
- full MIDI CC behind the scenes

### Deluxe = direct depth

- ADSR on panel
- modulation on panel
- arp on panel
- more switches
- more dedicated controls
- optional screen

## Final Recommendation

For the Light, the correct feature philosophy is:

- minimal hardware
- maximum clarity
- no fake limitation of the engine

For the Deluxe, the correct feature philosophy is:

- same engine
- more physical access
- more confidence in live use
- stronger premium desirability

In short:

- **Light should sell compact power**
- **Deluxe should sell immediate mastery**
