Kit jouable prepare a partir de la selection DMC.

Contenu :
- `wav/` : previews pour ecoute rapide
- `dmc/` : fichiers source renommes par role

Mapping MIDI suggere :
- `C1`  `36` : `01_kick_techno`
- `C#1` `37` : `02_kick_smb3`
- `D1`  `38` : `03_snare_heavyshred`
- `D#1` `39` : `04_snare_smb3_a`
- `E1`  `40` : `05_snare_smb3_b`
- `F1`  `41` : `06_rimshot_smb3`
- `F#1` `42` : `07_tom_1_gradius`
- `G1`  `43` : `08_tom_2_gradius`
- `G#1` `44` : `09_tom_3_gradius`
- `A1`  `45` : `10_tom_4_gradius`
- `A#1` `46` : `11_tom_5_gradius`
- `B1`  `47` : `12_voice_game_over`
- `C2`  `48` : `13_voice_disqualified`

Notes :
- l'ordre des toms est laisse volontairement en `tom_1..5`
- si tu veux, on pourra ensuite les reordonner apres ecoute
- les voix sont placees a la fin pour ne pas gener le jeu drum de base
